# StudyPlanner

## Project Overview

StudyPlanner is a student task and exam management application designed to help university students organize their academic responsibilities.

## Target Users

The application is intended for university students who need to manage assignments, exams, deadlines and study schedules.

## Problem Statement

Students often struggle to keep track of multiple assignments, exams and deadlines across different university subjects.

StudyPlanner aims to solve this problem by providing a centralized place for managing academic activities.

## Main Features

- Create new study tasks
- Edit existing study tasks
- Mark tasks as completed
- Delete unnecessary tasks
- Add upcoming exams
- View upcoming exams
- Receive exam reminders
- View tasks and exams in a calendar

## Project Structure

- `docs/` - Project documentation and data models
- `features/` - Functional specifications
- `tests/` - Test scenarios

## Development Methodology

The project follows the Kanban methodology.

Work is organized in Jira using:
- Epics
- User Stories
- Technical Tasks
- Bugs
- Subtasks

The Kanban board uses a Work In Progress (WIP) limit of 3 tasks in the In Progress column.

## Version Control

GitHub is used for version control.

Each work item has its own branch containing the Jira issue key. Changes are reviewed and merged into the main branch through Pull Requests.

## Implementation Status

This repository demonstrates software process management through Jira, GitHub and documented feature specifications. The full application has not been implemented.
