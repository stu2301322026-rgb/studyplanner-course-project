# StudyPlanner - Project Structure

StudyPlanner is a student task and exam management application.

## Project Organization

The project is organized into three main directories:

- docs/ - Project documentation and specifications.
- features/ - Descriptions of application features.
- tests/ - Test scenarios and acceptance tests.

## Main Functionalities

- Create, edit and complete study tasks.
- Manage upcoming exams and deadlines.
- Receive exam reminders.
- View tasks and exams in a calendar.

## Development Process

The project follows Kanban methodology.
All changes are tracked in Jira and integrated through GitHub Pull Requests.
