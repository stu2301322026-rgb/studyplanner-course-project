# Edit Study Task - Feature Specification

## Jira Reference
KAN-7 - Edit Study Task

## User Story
As a student, I want to edit existing study tasks so that I can update information when assignment requirements change.

## Functional Requirements
- The student can open an existing task.
- The student can edit the task title.
- The student can update the description.
- The student can change the university subject.
- The student can modify the deadline.
- The system saves the updated information.

## Acceptance Criteria
1. The student can edit the title and description.
2. The student can change the deadline and subject.
3. Changes are saved successfully.
4. Updated information is displayed after saving.
5. The task cannot be saved with an empty title.

## Validation Rules
- Task title is required.
- Invalid input is rejected.
- Validation errors are displayed to the user.
- Cancelling an edit leaves the original task unchanged.
