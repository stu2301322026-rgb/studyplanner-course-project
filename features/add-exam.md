# Add Exam - Feature Specification

## Jira Reference
KAN-10 - Add New Exam

## User Story
As a student, I want to add upcoming exams so that I can plan my preparation and avoid missing important dates.

## Functional Requirements
- The student can enter an exam title.
- The student can select a university subject.
- The student can select the exam date and time.
- The system validates required fields.
- The exam appears in the upcoming exams list after saving.

## Acceptance Criteria
1. The exam creation form contains title, subject, date and time fields.
2. Exam title and date are mandatory.
3. The system displays validation errors for missing required fields.
4. Successfully saved exams appear in the upcoming exams list.

## Subtasks
- KAN-14: Create exam form.
- KAN-15: Validate exam input data.
